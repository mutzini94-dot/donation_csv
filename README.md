# 후원 내역 분석

투네이션 후원내역 CSV를 읽어 후원액 추이, 시간대, 유형·금액대, 도네이터별 기록, 주간 요약을 보여 주는 단일 HTML 페이지입니다.

- `index.html`을 브라우저로 열면 바로 동작합니다. 서버나 빌드가 필요 없습니다.
- 기본 데이터는 482건 후원 내역을 익명화한 것입니다. 도네이터 닉네임은 `도네이터01`처럼 바꿨고 내용 열은 비웠습니다.
- 툴바의 **CSV 업로드**로 같은 형식의 CSV를 올리면 모든 화면이 그 데이터로 다시 계산됩니다. 파일은 브라우저 안에서만 읽고 어디로도 보내지 않습니다.

## CSV 형식

| 열 | 필수 | 예 |
|---|---|---|
| 시간 | O | `2026-08-19 07:10` |
| 도네이터 | O | 닉네임 |
| 금액 | O | `30800` |
| 등급 · 유형 · 내용 · 출처 | | `VVIP`, `텍스트`, 메시지, `일반` |

UTF-8과 EUC-KR(엑셀에서 저장한 CSV) 모두 읽습니다. 여러 파일을 한 번에 올리면 합쳐서 분석하고, 파일끼리 겹치는 행은 한 번만 셉니다.
